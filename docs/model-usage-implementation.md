### 验收口径

1. 同一筛选条件下，分组金额之和与汇总相等；未估价调用不被当作免费调用，均价分母只使用已估价调用。
2. 今日/月度和日期筛选固定北京时间；结束日期包含当天。
3. 同名模型不同供应商实例分开统计；无可信价格匹配时保持未估价。历史记录未保存实例时显示“历史未区分”，不猜测归属。
4. 官方目录更新不会改变已保存的历史金额及价格快照；客户端不可修改单价，旧自定义规则不再参与新请求计价。
5. 导出包含所有匹配记录而不是当前页，只有当前账号可见数据；不导出密钥、提示词和原始媒体。
6. 第一期的采集、未知状态、独立同步和平台积分规则保持兼容。
