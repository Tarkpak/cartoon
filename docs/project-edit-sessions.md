# 项目编辑会话

同一项目同一时刻只允许一个编辑会话。其他成员可以查看内容；项目所有者和管理员可以确认后接管。编辑会话按账号、设备和窗口区分，同一账号的两个窗口也不能同时编辑。

这是当前工作台快照同步协议的限制。新的按对象协作服务和 Rust 接口已实现，但尚未在工作台开放；迁移边界、接口和实施状态见 [按集协作迁移](project-collaboration-migration.md)。

## 行为

- 进入项目先取得云端租约，再同步本地待提交内容并读取云端最新快照。已有冲突不会自动覆盖，仍通过“处理冲突”入口选择版本。
- 租约有效期为 90 秒，客户端每 30 秒续租。退出时提交待同步内容并释放；客户端崩溃后租约自动过期。
- 冲突核对窗口每 20 秒续租，关闭时释放。租约失效或处理请求失败后，需要重新核对版本，磁盘备份不会删除。
- 交互请求等待云同步锁超过 5 秒返回繁忙错误；后台项目重试按项目释放锁。冲突读取云端版本的总预算为 45 秒，读取后会再次检查编辑权。
- 本地保存、项目生成请求和云端同步均校验编辑会话。云端同步仍校验 `baseUpdatedAt`，编辑锁不替代版本校验。
- 断线、过期或接管后切换为只读，并备份页面上的未同步修改。备份失败时保留当前页面内容并提示不要关闭；离开页面前必须先保存或完成备份。
- 视频任务记录启动时的租约，后台按项目续租。离开页面后，相关任务完成并同步后再释放。接管后旧任务保留生成结果，但不更新分镜或抽取声音资产。
- 只读用户不自动取得编辑租约。权限仍由原有项目角色和权限决定，租约不能提升账号权限。

## 部署

云端和客户端需要配套更新。建议在短暂维护窗口暂停项目编辑，先更新云端，再更新全部客户端。云端更新后旧客户端的项目上传会被拒绝；新客户端连接尚未更新的云端时会保持只读。尚未上传的旧客户端修改不会被删除，应在升级后进入项目并核对同步状态。

云端启动时自动新增 `project_edit_leases` 表，无需人工迁移，也无需新增环境变量。客户端租约存于本地 `system_config`；退出账号时清除。

客户端数据目录中的 `project-edit-backups/` 保存失去编辑权前的未同步内容，`project-conflict-backups/` 保存冲突处理前的本地和云端快照。备份是 JSON 数据和媒体地址，不包含媒体文件副本。页面支持下载当前未同步修改备份，冲突弹窗支持下载两份冲突快照。

## 接口

- 云端 `POST /api/client/projects/edit-session`：`acquire`、`heartbeat`、`check`、`release`、`takeover`。只有持有者收到租约 token，只有所有者和管理员可接管。
- 云端 `POST /api/client/projects/sync`：必须携带有效的 `editLeaseToken`，失效返回 423；版本不一致仍跳过同步。
- 客户端 `POST /api/project/{id}/edit-session`：取得、续租、释放或接管；请求通过 `x-project-edit-session` 区分窗口。租约 token 保留在本地后端。
- 客户端 `POST /api/project/{id}/edit-session/backup` 与 `GET /api/project/{id}/edit-session/backup/{backupId}`：保存和下载未同步修改。下载仍要求项目导出权限。
