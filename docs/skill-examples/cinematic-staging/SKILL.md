依据原剧本和已确定的分镜细化执行描述：

1. 明确每个主体在画面中的位置、朝向、视线和相对距离。
2. 交代动作的起始状态、过程、收束以及道具接触关系。
3. 写明景别、机位高度、运镜或固定镜头的持续状态，以及主光方向。
4. 按原镜头时长安排连续时间段，把原对白落到对应的动作和节奏上。
5. 保留原始剧情、对白、角色与资产 ID，不增加人物、道具和总时长。

参考 references/example.md 的细节密度，不照抄示例事实或时间。
