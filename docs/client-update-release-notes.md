# 客户端跨版本更新说明

更新检查接口按 `(当前版本, 目标版本]` 汇总已发布且平台、架构和渠道匹配的版本说明，按版本倒序展示。例如 1.0.100 升级到 1.0.105 展示 101～105，104 升级到 105 只展示 105。

发布脚本现在同时上传 `desktop-updater/release-<version>.json` 和 `latest.json`。后台“同步更新版本”会读取这些历史清单，补齐旧版本说明；安装包目录本身无法恢复更新说明。历史清单读取失败会通过同步结果的 `listWarning` 返回。

上线时需要部署后台并执行版本同步。此前已发布的版本需要从对应 GitHub Release 使用 `desktop:publish-updater-cdn --tag=v<version>` 重新发布元数据，或在后台补填各版本说明。该发布命令也会覆盖 `latest.json`，因此应按版本从旧到新执行，最后重新发布当前最新版本，再同步；不能只重发旧版本后就结束。请使用原发布环境中的 GitHub 和云存储凭证。

客户端直接使用 Tauri 静态 `latest.json` 的兜底检查仍展示清单里的最新版本说明；按当前版本汇总由云端更新检查接口提供。
