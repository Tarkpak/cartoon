# 剧本目录上下文预算

生成分集目录前，检查包含原文、模板、画风和人物身份表的完整提示词。
当前使用 48,000 UTF-8 字节的保守输入预算，不依赖第三方供应商的 tokenizer。
它不是精确 token 计数，也不能保证兼容所有小上下文模型；输出仍由现有模型配置控制。

- 超预算时按段落或句末递归拆分原文，保留每个字符和全局偏移。
- 每段生成后继续携带已确认的人物身份，重新检查下一段的完整提示词。
- 人物姓名、ID、别名始终保留；仅本段原文明示涉及的人物携带完整外观。
  未在提示词中展开的外观仍留在完整登记表中，用于校验和最终资产恢复。
- 未定义人物引用最多修复一次。修复请求只包含本段原文、身份资料、已有新增人物和精简引用表。
  模型只补充人物档案，代码合并补丁，不允许补丁重写分集或覆盖已定义人物。
- 修复请求也检查预算；如果资料或自定义模板本身过大，明确报错，不静默截断。

这些规则仅覆盖分集目录及其人物修复，不会自动摘要所有产品对话。
分镜修改对话已有最多 12 条、每条 1,200 字的校验，保持原有行为。
无数据库迁移或环境变量变更。
