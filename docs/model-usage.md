# 模型用量与费用

三期功能范围、实施进度与验收记录见 [实施计划](./model-usage-implementation.md)。当前已提供第一期采集闭环与第二期成本分析功能。

入口为「日志 → 用量与费用」。模型日志详情、模型测试结果、分集目录和剧本解析完成/失败后也展示关联调用用量。

## 采集范围

- Rust 后端的 OpenAI / 自定义 OpenAI 兼容文本和图片生成、图片编辑，包括模型测试。
- 通义千问与 DeepSeek 的统一文本调用入口（包括模型测试、剧本解析等业务）；通义图片生成/编辑、视频终态查询与恢复查询、语音合成接口也采集原生用量。
- 官方 Chat Completions 流开启 `stream_options.include_usage`；JSON / SSE usage 单独提取，不依赖 choices 内容。
- 每次实际请求重试单独记录，任务使用 request ID 汇总。取消/未读完响应保留未知记录，失败不等于免费。流式截断继续读取末尾 usage，再返回业务错误。
- 缓存输入属于输入明细，推理属于输出明细，不重复累计；图片文字输入和图片输入分别计价。
- 仅反映本应用采集的调用，不是 API Key 全局账单。历史日志暂不回填。

## 计价与持久化

价格版本 `openai-2026-11-05-v2` 来源 https://developers.openai.com/api/docs/pricing。`shared/openai-pricing.json` 维护统一价格目录，Rust 与云端共用；单价采用整数微美元/百万 token，费用采用整数 USD 纳美元，最后四舍五入到纳美元。更新目录必须增加版本号并补充计价测试；已经保存的费用不重算。

`openai` 供应商按官方参考价估算，包括配置代理 endpoint 的情况；这不代表代理实际成交价。`custom_openai` 无可信价格匹配时仅统计用量，费用显示未估价，不支持客户端自定义单价。文本费用 = 非缓存输入 × 输入单价 + 缓存输入 × 缓存单价 + 输出 × 输出单价；推理 token 已包含在输出中。图片按文字输入、图片输入、图片输出分别计价。目录覆盖当前页面 36 个文本模型、8 个图片模型，并按有明确价格的 Standard、Flex、Fast/Priority、Ultrafast 档位和长上下文分别计算。

未知模型/服务档位、缓存写入，以及缺少图片必要分项或存在暂不支持的图片缓存/混合输出时保留 token 并显示未估价。当前应用未接入的 Batch、音频、嵌入、工具独立收费及区域加价不纳入此 token 估算。预算和事前估算属于待实施的第三期。

启动时仅为已有独立台账中 token 完整、尚无金额且能匹配目录的 OpenAI 记录补算，保存当前价格版本；它不是历史账单重建。已经估价的记录不覆盖。只有旧日志而无独立台账的记录不回填。

SQLite 自动新增独立 `model_usage_records` 表和索引，无需环境变量。清理 debug 日志不清理用量。用量写入错误会输出诊断，不中断已经成功的模型结果。

## 同步和权限

云端 Bun 数据库也自动新增用量表，以 `(user_id, id)` 幂等写入。记录通过日志上传附带，同时本地独立待同步队列每 30 秒补传，避免日志清理导致丢失。新增 `/api/client/model-usage` GET/POST，仅允许认证账号自己的记录；本地 `/api/model-usage` 也限定当前账号。正常云端同步拉取全部分页记录，并在账号切换时停止导入。

桌面端和云端需一起更新；旧云端返回 404 时本地台账继续记录，待更新后重试。云端记录仅用于统计，不参与现有积分扣费；客户上报的金额不作为结算依据。

## 展示口径

今日/月度边界固定 Asia/Shanghai。金额为已估价调用之和；同时展示估价覆盖数和未知用量调用数，未知不按零计价。明细默认每页 50 条，汇总涵盖全部匹配记录。UI 的“输入/输出”只累加已知数量。

## 第二期：分析、官方计价与导出

### 项目和模型分析

在「日志 → 用量与费用」按起止日期、项目、供应商实例、模型和业务环节筛选。结束日期包含当天。筛选范围汇总及其中的今日/月度汇总都应用同一组条件；翻页不改变汇总。统计在 SQLite 读事务中完成，避免并发新调用导致分组与总额不一致。

项目与业务环节分布展示已估价费用占比和未知用量数，点击某项可继续筛选。工作台右上角「项目用量」直接打开对应项目。仅统计当前账号的调用，不等于整个协作项目所有成员的账单。

模型对比按实际供应商实例、响应模型及环节分组，展示调用数、已估价数、输入/输出 token、费用和单次均价。均价仅除以已估价次数；调用任务、输入规模不同，不能据此判断模型质量。普通文本环节包含剧本解析，技能调用额外区分分镜细化/视频审查。

第二期新增记录包含实例身份与名称；历史未采集实例的记录归为“历史未区分”，不根据当前供应商配置猜测。实例键包含供应商配置 ID 和清理敏感字段后的 endpoint 摘要，更改 endpoint 会成为新实例；启停供应商或更换 API Key 不改变实例身份。

### 官方价格维护

客户端只展示用量和费用，不提供自定义单价。OpenAI、Seedance、通义和 DeepSeek 的官方价格由代码中的版本化目录统一维护，目前没有后台价格配置页面。

已移除客户端价格编辑入口和 `GET/PUT /api/model-usage/prices` 接口。旧设备保存的自定义规则不再读取，也不参与新请求计价；历史台账金额及价格快照保留，不重新计算。

自定义兼容供应商未匹配可信价格目录时，仅记录上游返回的用量，费用显示“未估价”。不会把同名模型直接视为官方供应商报价。流式 `stream_options.include_usage` 对 `openai`、`qwen`、`deepseek` 供应商自动开启；兼容接口未返回 usage 时保持未知。

### 明细导出

点击「导出筛选明细 CSV」可下载当前筛选下的全部记录，不受每页 50 条限制。UTF-8 BOM 格式方便 Excel 打开，字段含调用 ID、UTC 时间、项目 ID、实例、模型、环节、结果、分项 token、用量状态、USD 估价与价格版本；未知数量/金额留空。文本按 CSV 引号规则转义，公式起始符加前导单引号，避免公式注入。不导出提示词、密钥或媒体。

接口：`GET /api/model-usage/export`，与统计查询复用账号隔离和筛选校验；`/api/model-usage` 新增 `startDate/endDate/projectId/providerInstanceId/model/stage/page/pageSize`。

## 云端管理后台

后台侧栏「用量与费用」（`/model-usage`）展示已经同步到云端的用量。默认查看北京时间本月，可按日期、用户、供应商、实际响应模型及项目 ID 筛选，支持调用明细分页。汇总涵盖全部匹配记录，包含调用次数、已知输入/输出 token、未知用量次数、已估价费用和估价覆盖数。

客户端与后台「调用日志」列表都提供「消耗量 / 费用」列，直接展示输入/输出 token 与原币种估价。后台日志详情、费用排序和 CSV 导出使用同一台账金额；积分单独展示。日志通过账号及调用事件 ID 精确关联台账，不按 request ID 合并，避免重试或其他用户的调用金额串行。小额费用保留到纳货币单位，不显示为免费；缺少数据时显示“未采集用量 / 未估价”。

用户费用排行、供应商实例/模型对比分别显示费用前 20 项，单次均价仅以已估价调用为分母。管理员可查看所有用户；`GET /api/admin/model-usage` 在查询前校验管理员权限。接口仅返回统计所需字段，不返回原始 usage、密钥或提示词。筛选、分组及分页使用同一数据库读事务。

云端金额属于客户端上报的历史估价，不作为平台结算依据；未同步调用不会出现。官方价格目录由代码统一维护，无需客户端配置。无需新增环境变量，更新云端服务后页面和接口生效。

## Seedance 官方计价（人民币）

通义与 DeepSeek 的采集、价格和限制见文末补充。

官方来源：[火山方舟模型价格](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh#02affcb8)，核对于 2026-11-05；[查询视频任务 API](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh) 返回实际 `usage.completion_tokens`、模型、分辨率及服务档位。

`shared/seedance-pricing.json` 是客户端 Rust 与云端共用的版本化价格目录。当前接入火山 `volcengine` 的 Seedance 视频生成完成及恢复查询路径。在线单价如下，单位为人民币/百万计费 token，双值分别为「无视频输入 / 有视频输入」：

| 模型 | 480p / 720p | 1080p | 4K |
| --- | --- | --- | --- |
| Seedance 2.5 | 70 / 42 | 77 / 46 | 不支持 |
| Seedance 2.0 | 46 / 28 | 51 / 31 | 26 / 16 |
| Seedance 2.0 Fast | 37 / 22 | 不支持 | 不支持 |
| Seedance 2.0 Mini | 23 / 14 | 不支持 | 不支持 |

Seedance 1.0 Pro 在线 15 元、离线 7.5 元/百万 token；1.0 Pro Fast 在线 4.2 元、离线 2.1 元/百万 token。仅对官方目录中明确的型号及版本后缀匹配，不猜测未知型号或接入点对应的模型。

费用 = API 返回的 `completion_tokens` × 对应单价 / 1,000,000。输入视频最低 token 用量已由上游返回值体现，不再用秒数或分辨率示例重复估算。成功但无 token、分辨率或参考视频信息不足时显示未估价。终态 failed/cancelled/expired 按官方失败不收费记 ¥0；查询 HTTP 错误不等同于任务失败，不据此记免费。

仅终态任务写入视频用量台账；提交、排队、处理中不重复写入费用。按账号、上游任务 ID 和 endpoint 生成稳定事件 ID，轮询与恢复查询重复返回同一任务不会重复计费。不同 Draft/正式任务的上游 ID 分别计数；如果未来请求只给 Draft 来源而未保留原始参考视频信息，保留未估价，不能按无视频输入猜价。版权 IP 附加费用不包含在视频 token 估价中。

日志「消耗量 / 费用」展示 `¥` 金额与视频计费 token。分析页新增 USD / CNY 筛选，汇总、分组、均价及排行在所选币种内计算；混合调用的紧凑汇总并列显示两种币种。CSV 分列导出 USD、CNY 金额及币种，不自动换汇。人民币保存为 `costNanoCny`，不复用 `costNanoUsd`；平台每秒积分扣费规则保持独立。

## 通义与 DeepSeek 统计

价格目录为 `shared/qwen-deepseek-pricing.json`，版本 `qwen-deepseek-2026-11-05-v1`，Rust 与云端 TypeScript 使用同一目录和共享计价用例。

- 官方来源：[通义模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)、[通义缓存计费](https://help.aliyun.com/zh/model-studio/context-cache)、[DeepSeek 价格](https://api-docs.deepseek.com/quick_start/pricing)。
- 通义文本：采集输入、输出、缓存和推理 token；按单次输入总量选择整笔请求的阶梯。目录覆盖 3.8 Max/Flash、3.7 Max/Plus/Flash、3.6 Plus、qwen-max、qwen-long 及目录明确列出的版本。缓存创建、特殊服务档位、未知模型保持未估价。3.8 Max/Flash 的隐式缓存单价需控制台确认，因此命中缓存时不猜价。
- 通义价格仅匹配北京官方域名（`dashscope.aliyuncs.com` 或业务空间 `.cn-beijing.maas.aliyuncs.com`）；其他地域和代理域名仍采集用量，但不套用北京价格。使用公开原价，不扣免费额度、资源包或限时优惠。
- DeepSeek 文本：支持 `prompt_cache_hit_tokens`，缓存不重复累加。目录覆盖 `deepseek-flash`、`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`、`deepseek-v4-pro`。**当前按官方高峰参考价估算，不计算低峰及中国节假日折扣**，页面会注明；因此不是供应商实际扣款。Flash 输入/缓存/输出分别为 $0.30/$0.006/$1.20 每百万 token，Pro 为 $1.32/$0.044/$3.96。
- 通义图片：采集 API `usage.image_count` 与请求输入图片数量，以张展示。目录覆盖 Qwen Image 3.0、2.1 Pro/Turbo、2.0/Pro、Wan 2.7 Image/Pro、Wan 2.6 Image；3.0 Pro 等尚未匹配完整计价规则的型号保留用量、未估价，不拿图片张数当 token。
- 通义视频：只记录 SUCCEEDED/FAILED/CANCELED 终态，以供应商、查询 endpoint、账号、上游 task ID 稳定去重，正常轮询与重启恢复不重复累加。读取 `usage.output_video_duration`（回退 `duration`）、`input_video_duration` 和 `SR`；万相 3.0/Prime 按输入加输出秒数，Wan 2.7 T2V/I2V、2.6 T2V/I2V 按输出秒数和分辨率估价。HappyHorse、参考生视频等未配置价格的型号仍统计返回的时长；缺失时长/分辨率、终态失败不猜零费用。提交任务、处理中和查询 HTTP 错误不另计生成次数。
- 通义语音合成：采集上游 `usage.characters` 并展示字符数，暂不估价。未提供字符数时标记未知。不包含尚未接入采集的其他语音识别接口。

客户端模型测试结果、日志列表/详情、用量分析与云端管理后台共用台账；日志与明细展示 token/张/秒/字符，CSV 保存原生单位。汇总 token 只累加实际 token 字段，媒体单位不折算成 token。新增字段可自动同步，无需新增环境变量或客户端价格设置；需重启 Rust 后端并更新云端服务。历史日志不回填，已有费用快照不重算。

客户端需重新编译/重启 Rust 后端，云端需更新服务。只有旧日志而无采集数据的视频不回填；未进行真实付费视频生成验收。
